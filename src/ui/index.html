Chopshop

Chopshop builds unofficial mods for the Elektron Analog Rytm (MK1 and MKII, OS 1.73) and the Analog Keys (OS 1.56) from Elektron's own OS file, right here in your browser. Then you flash the checked file with Elektron Transfer.

Watch the demo video (opens YouTube; this page itself needs no network).

Source code on GitHub (opens GitHub; this page itself needs no network).

Supported units: Analog Rytm MK1 and MKII (OS 1.73) and Analog Keys (OS 1.56), and nothing else. The Analog Four is not supported.

  • Analog Rytm MK1 run on a unit (see each build)
  • Analog Keys run on a unit (see each build)
  • Analog Rytm MKII NOT run on a unit yet

Nothing is uploaded: your file never leaves this computer, and the page works offline. Unofficial: not made, checked or endorsed by Elektron. Changing your unit's firmware is at your own risk.

Read this first: OS 1.74

Elektron's support pages now serve only OS 1.74 for the Analog Rytm MK1 and MKII. These mods are built for OS 1.73. (The Analog Keys mods are built for OS 1.56, which Elektron still serves as of October 2026.)

  • A Rytm that is already on 1.74 can't be loaded with these files. They are built for 1.73, this page will not build anything from a 1.74 file, and putting a 1.73-based file on a 1.74 unit would be a downgrade, which Elektron does not support. Don't try it.
  • Going back to 1.73 on an MKII that is on 1.74 is likely not possible. That is unverified: nobody has tried it here. Ask Elektron support before you try anything. Elektron's own release notes say that downgrading the device OS is not supported, is at your own risk, and can lose user content. Whether an MK1 can go back is equally unverified.
  • Still have Elektron's original 1.73 file (a copy or backup from before you updated), and a unit that is still on 1.73? Use that file here: the page recognises it by its checksum. Don't update the unit to 1.74 if you want these mods.
  • A 1.74 port is planned as a follow-up. There is no date, and nothing on this page works with 1.74 yet.

Which file do I need?
  • Analog Rytm MK1: Elektron's OS 1.73 file (Analog-Rytm_OS1.73.syx).
  • Analog Rytm MKII: Elektron's OS 1.73 file for the MKII (Analog-Rytm_MKII_OS1.73.syx).
  • Analog Keys: Elektron's OS 1.56 file (Elektron publishes one file for the Analog Four and the Analog Keys; only the Analog Keys is supported here).

The page recognises these files by their exact checksum, so a renamed file is fine and a changed one is refused. Your unit must run the same OS version as the file.

Unit on OS 1.72? First install Elektron's original 1.73 file the normal way (Elektron Transfer, its drop page). Then come back with that 1.73 file and flash the Control build first.

On OS 1.74? See the note at the top of this page: these mods are for 1.73 (Keys: 1.56), and this page will not build from a 1.74 file.

3 Build and check

First drop your OS file and choose.

The page unpacks your file, adds the mods, packs it again and then checks the result: the recovery code untouched, nothing changed outside the mods, and the finished file identical, byte for byte, to the one the project published. It takes from a few seconds to a minute, depending on the computer. The download only appears when every check has passed.

4 Flash it with Elektron Transfer

  
Download the checked file in step 3, then install it with Elektron Transfer, Elektron's own program. This page does not send anything to your unit itself.


  

    
Before you start

    
    
      
  • Back up your projects (and +Drive) in Elektron Transfer first.
    • 
      
  • Flash the Control build first (step 2, no boxes ticked). If the unit starts and plays normally, the route works. Then add one mod at a time, each only after the one before behaved (your device's START_HERE has the order).
    • 
      
  • Don't power off the unit while it installs, or during the first start after it.
    • 
      
  • Keep Elektron's original OS file: the recovery route sends it. Going back to stock over a mod build has not been tried on a unit yet.
    • 
    

  


  
The steps

  
    
    
  1. Connect the unit to the computer with USB, start Elektron Transfer, choose the unit as MIDI in and MIDI out, and click Connect.
    2. 
    
  2. Drag the downloaded .syx file onto Transfer's big DROP area ("Drop files here"). Then press YES on the unit, as the project's notes for your device say.
    3. 
    
  3. Follow the unit's screen. Do not switch it off during the update or during the first start after it.
    4. 
    
  4. If Transfer refuses the file as "same version", nothing was written. Stop, or use the startup-menu route below.
    5. 
  

  
These are the steps of the project's own notes for each device and of Elektron's article How to update your device (opens Elektron's site; this page itself needs no network).


  

    
Analog Rytm MK1 (OS 1.73)

    
If the unit doesn't start, or Transfer refuses the file: use Elektron's startup-menu route with Elektron's original 1.73 file. Hold FUNC while you switch the unit on, then press TRIG 4 (OS UPGRADE). In Elektron Transfer click "go to the SYSEX TRANSFER page", then "OS upgrade via device startup menu" (the project's notes call this CONNECTION page button "LEGACY OS UPGRADE"), and follow the screen. This needs a DIN MIDI interface and a MIDI cable into the unit's MIDI IN: USB does not work in the startup menu.

    
Elektron's text: Analog Rytm MK1 manual, section 14.4 "OS UPGRADE", and the article How to update your device via sysex transfer. The project's first-run checks for these files: flash/START_HERE.md.

  


  

    
Analog Rytm MKII (OS 1.73)

    
No MKII build has been run on an MKII, not even by the author.

    
They are built and verified byte for byte, nothing more. Flash the Control build first and read the notes before you try the others.

    
If the unit doesn't start, or Transfer refuses the file: use Elektron's startup-menu route with Elektron's original 1.73 file. Hold FUNC while you switch the unit on, then press TRIG 4 (OS UPGRADE), and in Elektron Transfer use the CONNECTION page's "LEGACY OS UPGRADE" mode (Elektron's wording in the MKII release notes). This needs a DIN MIDI interface into the unit's MIDI IN: USB does not work in the startup menu.

    
Elektron's text: the Analog Rytm MKII OS release notes, "Upgrading from the STARTUP Menu", and the article How to update your device via sysex transfer. The project's notes: flash/MKII/START_HERE_MKII.md.

  


  

    
Analog Keys (OS 1.56)

    
The Control, chord memory and chord + JOY RANDOM builds have run on the author's Analog Keys, and worked. JOY RANDOM alone has not been run separately. Every build is also verified byte for byte here. Flash the Control build first and read the notes before you try the others.

    
If the unit doesn't start, or Transfer refuses the file: use Elektron's startup-menu route with Elektron's original 1.56 file. Connect your MIDI interface's output to the Keys' MIDI IN (DIN). Hold FUNCTION while you switch the unit on, then press TRIG 4 (OS UPGRADE). In Elektron Transfer click "go to the SYSEX TRANSFER page", then "OS upgrade via device startup menu", and follow the screen. USB does not work in the startup menu.

    
Elektron's text: Analog Keys manual, "EARLY STARTUP MENU" and "OS UPGRADE", and the article How to update your device via sysex transfer. The project's notes: flash/KEYS/START_HERE_KEYS.md.

  






  
If something goes wrong

  
    
    
  • Transfer shows an error, or the unit shows one: if the unit's screen says it is upgrading, don't switch it off: wait. Otherwise start again from step 1 of section 4. If Transfer refuses the file as "same version", nothing was written.
    • 
    
  • The unit doesn't start after flashing: use Elektron's startup-menu route in step 4 (your unit's box) with Elektron's original OS file, the one you dropped in step 1. These mods never change the recovery code: before offering a download, the page checks byte for byte that the file leaves it exactly as Elektron made it.
    • 
    
  • Only flash a file onto the unit it was built for. The page builds Rytm files only from Rytm files, and Keys files only from the Keys file.
    •
