Rytm & Keys Mod Installer working name

Builds unofficial mods for the Elektron Analog Rytm (MK1 and MKII, OS 1.73) and the Analog Keys (OS 1.56) from Elektron's own OS file, right here in your browser. Then it can send the result to your unit over MIDI.

Nothing is uploaded: your file never leaves this computer, and the page works offline. Unofficial: not made, checked or endorsed by Elektron. Changing your unit's firmware is at your own risk.

1 Your Elektron OS file

Drop Elektron's original OS update file here: the .syx file, or the _dist.zip it came in.

Drop the file here

or

Which file do I need?
  • Analog Rytm MK1: Elektron's OS 1.73 file (Analog-Rytm_OS1.73.syx).
  • Analog Rytm MKII: Elektron's OS 1.73 file for the MKII (Analog-Rytm_MKII_OS1.73.syx).
  • Analog Keys: Elektron's OS 1.56 file for the Analog Four / Analog Keys.

The page recognises these files by their exact checksum, so a renamed file is fine and a changed one is refused. Your unit must run the same OS version as the file.

OS 1.74 is not supported yet. In October 2026 Elektron's site offers only 1.74 for the Rytm. If your Rytm is on 1.73, don't update it: going back to an older OS is a downgrade, which Elektron does not support.

Mods for your unit

First time? Leave every box empty: that gives the Control build, Elektron's own code repacked by this tool and nothing else. Flash it first. If your unit starts and plays normally, the whole route works, and you can come back for the mods.

3 Build and check

First drop your OS file and choose.

The page unpacks your file, adds the mods, packs it again and then checks the result: the recovery code untouched, nothing changed outside the mods, and the finished file identical, byte for byte, to the one the project published. It takes from a few seconds to a minute, depending on the computer. The download only appears when every check has passed.

4 Send it to your unit over MIDI

  
This uses the unit's own startup menu (OS UPGRADE), the same way Elektron's recovery works. It also works when the unit no longer starts normally.


  

    
You need

    
    
      
  • Chrome or Edge on a computer. Firefox only with an extra add-on; Safari can't send MIDI from a web page. 
    • 
      
  • A DIN MIDI interface (the round 5-pin MIDI plugs) and a MIDI cable. USB does not work in the startup menu: the unit only listens on its MIDI IN socket there.
    • 
      
  • About 10 to 15 minutes at the recommended pause, with the computer awake and this page in front.

    What this page can and can't see
    
It sends the file's own MIDI messages, unchanged and in order, with the pause you chose. It is not known whether the startup menu answers over MIDI, and this page does not listen for an answer, so it can't tell whether the unit received everything: watch the unit's screen.

If something goes wrong

  
    
    
  • The unit shows an error, or nothing happens: switch it off, then start again from step 1 of section 4. Try a longer pause. Check the cable goes into MIDI IN.
    • 
    
  • You stopped the transfer: if the unit is still waiting or receiving, switch it off and start again. If its screen says it is upgrading, don't switch it off: wait.
    • 
    
  • The unit doesn't start after flashing: use the same steps with Recover: send Elektron's original file. These mods never change the recovery code: before offering a download, the page checks byte for byte that the file leaves it exactly as Elektron made it.
    • 
    
  • Only send a file to the unit it was built for. The page builds Rytm files only from Rytm files, and Keys files only from the Keys file.
